# v0a pipeline dependencies
# Python 3.12 or 3.13 (gensim has no prebuilt wheel for 3.14 yet).
#
# Version notes:
# - gensim>=4.4 is required: 4.4.0 (2025-10-13) added NumPy 2.0 support and
#   Python 3.13 wheels. Earlier 4.3.x releases pin numpy<2.0, which would
#   silently downgrade numpy if resolved instead of 4.4+.
# - numpy is intentionally left unpinned on the upper end now that gensim,
#   spaCy, and scikit-learn all support NumPy 2.x.
# - openpyxl is required by pandas.read_excel() to read the .xlsx dataset.
# - spacy is used by preprocessing/normalize_vocab.py (SpacyNormalizer).
# - click is pinned explicitly as a workaround for a current spaCy bug:
#   spaCy's CLI imports `click` directly but relies on typer to pull it in
#   transitively; typer>=0.26 dropped click as a dependency, so a fresh
#   `pip install spacy` now fails with `ModuleNotFoundError: No module
#   named 'click'` unless click is installed separately.
#   Tracking issue: https://github.com/explosion/spaCy/issues/13971
# - ingredient-parser-nlp is used by nutrient_table_labeling/build_corpus_labels.py

pandas>=2.0
openpyxl>=3.1          # pandas needs this to read .xlsx files
gensim>=4.4,<5.0        # numpy 2.0 support + Python 3.13 wheels (see notes)
numpy>=1.24             # no longer capped below 2.0, see notes above
scipy>=1.10
scikit-learn>=1.3       # PCA in harness/visualize.py
matplotlib>=3.7         # plotting in harness/visualize.py
spacy>=3.8,<3.9         # normalize_vocab.py SpacyNormalizer; matches en_core_web_sm-3.8.0
click>=8.1              # workaround for explosion/spaCy#13971 (see notes)
ingredient-parser-nlp==2.7.0   # second extraction method in build_corpus_labels.py
